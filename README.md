# RAM Chomper 🍽️🚀

Ever look at your task manager and think, *"Man, my RAM is just sitting there doing nothing. I paid for 32GB, I'm gonna use 32GB!"*? 

Welcome to **RAM Chomper**, the only app that exists solely to satisfy your hunger for memory consumption. It lives in your system tray, animates like a hungry beast, and eats your RAM on command.

## why?
- **Stability Testing**: See how your PC handles actual pressure.
- **Flexing**: Make your "Memory Used" graph look like a mountain range.
- **Spite**: Because you paid for those sticks and you'll be damned if they stay idle.

## ✨ Features
- **📍 Stealth Mode**: Lives in the tray. No windows, no clutter, just vibes.
- **🎨 Dynamic Theme**: Automatically turns white or black to match your Windows theme.
- **🍕 Custom Portions**: Eat a snack (512MB) or a full meal (4GB+). You can even set a custom weight.
- **🛡️ Safety First**: It won't let you crash your system. It keeps a tiny reserve so your OS doesn't have a heart attack.
- **📈 Stats**: Track your current "meal", your lifetime total, and your average load.

## 🛠️ Installation (for the nerds)
1. **Clone it**:
   ```bash
   git clone https://github.com/MuhammadWahaj/RAM_Chomper.git
   ```
2. **Feed it dependencies**:
   ```bash
   pip install psutil PyQt5 Pillow
   ```
3. **Release the beast**:
   ```bash
   python ram_chomper.py
   ```

## 📦 Running the EXE
If you don't want to mess with Python, just grab the `ram_chomper.exe` from the `dist` folder and run it. No setup, just chomp.
